# Переключение русского и английского языка

Добавлены кнопка «🌐 Сменить язык» в меню и профиле, команды /language и /lang.
Язык сохраняется для каждого пользователя в users.language. По умолчанию — русский.
Переведены приветствие, профиль, тарифы, кнопки, оплата Stars/CryptoBot,
донаты, пользовательские ошибки, интерфейс опросов и фоновые сообщения CryptoBot.
Личные тексты пользователей, названия каналов из настроек, вопросы и варианты
опросов, ответы администратора не переводятся автоматически.
Администраторская часть сохраняет русские служебные тексты.

## Обновление работающего бота

1. Остановите бот и сохраните резервную копию текущей bot.db.
2. Замените папку app из этого архива в вашем проекте целиком.
3. Оставьте вашу текущую .env и текущую базу данных. Не заменяйте рабочую
   базу старой копией bot.db из архива, если после загрузки проекта были изменения.
4. Запустите как раньше: python run.py. Поле language добавится автоматически;
   существующие пользователи получат русский язык по умолчанию.
5. Отправьте /start, выберите «🌐 Сменить язык» → English.

Новые переводы добавляются в app/services/translations.json:
русский исходный текст — ключ, английский — значение. Параметры {p0}, {p1}
в шаблонах должны совпадать. Новые тексты в коде оборачивайте в t(...).

## Проверки

После установки requirements.txt: python -m unittest discover -s tests -v
Проверены сохранение и переключение языка, меню и счета, миграция SQLite,
подстановки в переводах и изоляция языков между асинхронными задачами.
Реальные Telegram-сообщения и платежи при проверке не отправлялись.

Также устранено обращение к неопределённым переменным в crypto_invoice_keyboard.
